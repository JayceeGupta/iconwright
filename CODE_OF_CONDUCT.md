# Code of conduct

iconwright follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, keep feedback about the work, and don't harass anyone. This applies in issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

If someone's behavior makes you uncomfortable, report it privately to the maintainer through [a private security advisory](https://github.com/JayceeGupta/iconwright/security/advisories/new) (it's the one private channel GitHub offers; just say it's a conduct report). Reports are kept confidential. The maintainer may remove comments, lock threads or block people who break these rules.
