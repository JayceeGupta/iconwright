# Contributing

Testing on your computer is the most useful thing you can do right now: iconwright has only been tested on one Windows 11 PC.

1. Pick the [test prompt](docs/contributing.md#test-prompts) for your system (macOS, Linux, or Windows 10/11 with the stock taskbar) and paste it into your AI agent. It installs iconwright, runs a test plan, puts everything back, and writes a report.
2. Send the report as a [test report issue](https://github.com/JayceeGupta/iconwright/issues/new?template=test-report.yml), or add it to [`test-reports/`](test-reports/) in a pull request.
3. Know the fix? Open a pull request with the change and the report that shows the problem.

Details, the report template and how to work on the code: [docs/contributing.md](docs/contributing.md).
