Ask your agent to restyle Windows.

iconwright gives Claude Code, Codex and other AI agents the tools to make icons and change your taskbar and desktop. Every change can be undone.

Install

You need Windows 10 or 11 and Node.js 20 or newer. The first run installs the image library iconwright uses, which takes about ten seconds.

Run these two commands inside Claude Code:

/plugin marketplace add {{repoSlug}}
/plugin install iconwright@icon-playground

Then ask in plain words, like "make my Discord taskbar icon purple". The plugin adds the iconwright tools and a skill that teaches Claude to preview first and offer undo.

git clone {{repo}}
codex mcp add iconwright -- node C:/path/to/iconwright/bin/iconwright-mcp.mjs

Codex asks before each tool call. To run without asking in codex exec, pre-approve tools in ~/.codex/config.toml, as shown in the guide.

Clone the repository and run this as a stdio MCP server:

node C:/path/to/iconwright/bin/iconwright-mcp.mjs
git clone {{repo}}
cd iconwright
node bin/iconwright.mjs doctor
node bin/iconwright.mjs apply "Spotify" --source simple-icons:spotify --color white

Every command prints one line of JSON. node bin/iconwright.mjs help lists them all.

What it can do

Icons come from any of the 200,000+ icons on Iconify, or from your own SVG, PNG, JPEG, WebP or ICO files.

Make icons any OS
Recolor, add a rounded or circle background, and export a proper .ico with every size from 16 to 256 px. Agents see a preview before anything is applied.
Change app icons
On the taskbar, Start Menu and pinned shortcut. Most running apps update instantly.
Pin, unpin and reorder
Put apps on the taskbar and in the order you want, several at once with a single Explorer restart.
Arrange the desktop
Move icons, line them up in any corner, change their size, re-icon shortcuts and folders, show or hide This PC and Recycle Bin, and save layouts.
Undo anything
Original icons are remembered, and the pinned-apps list is backed up before every change. One command puts it all back.
Check its own work
doctor checks your PC before the first change. capture screenshots the taskbar or desktop so the agent can see the result.

Know the risks

iconwright is an early release (0.1). It has been tested on one Windows 11 PC. Try it on a machine where a reset taskbar wouldn't ruin your day.

  1. Windows updates could break pinning.Pins are stored in a format Microsoft doesn't document. iconwright refuses to edit it if anything looks unfamiliar, but a future update could change it.
  2. Pinning restarts Explorer.The taskbar blinks for a second or two and open File Explorer windows close. Your apps keep running.
  3. Taskbar styling tools can switch off.TranslucentTB disables itself if Explorer restarts twice quickly. iconwright notices, restarts it and can space restarts out.
  4. App updates can undo a custom icon.Some apps recreate their shortcut when they update. Apply the icon again.
